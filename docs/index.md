# Microsoft Teams Bridge — Documentation

The Microsoft Teams Bridge app enables seamless cross-platform communication between Rocket.Chat and Microsoft Teams. Messages, files, and member updates are relayed in real time so that users on each platform can collaborate without leaving their preferred tool.
